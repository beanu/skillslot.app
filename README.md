# SkillSlot

**让散落在本地的 Agent Skills 变得可见、可懂、可组合、可部署。**

SkillSlot 是一款本地 Agent Skill 管理工具。它会自动发现散落在不同目录和工具中的 Skills，把它们收进一个清晰的 Vault，再按任务组合成可复用的 Loadout，一键部署到你正在使用的 AI 编程 Agent。

不再手动复制文件夹，不再记忆复杂路径，也不必为不同 Agent 重复安装同一套 Skills。

[访问 SkillSlot 官网](https://skillslot.app) · [免费下载试用](https://github.com/beanu/skill-less/releases/latest)

## 用 SkillSlot，你可以

- **统一收纳**：自动扫描本地 Skills，集中管理，快速搜索。
- **按任务组合**：为前端开发、代码审查、数据分析等场景创建专属 Loadout。
- **一键部署**：把需要的 Skills 快速切换到目标 Agent 或工作目录。
- **跨 Agent 复用**：同一份 Skill 可用于多个 AI 编程 Agent，无需重复维护。
- **安心留在本地**：无需账号，数据保存在你的 Mac 上。

## 它适合谁？

如果你同时使用多个 AI 编程 Agent，积累了越来越多的 Skills，并且经常需要在不同项目和任务之间切换，SkillSlot 能让这套工作流重新变得清晰、稳定而高效。

**3 分钟完成第一次部署。无需注册。**

需要 macOS 12.0 或更高版本。
